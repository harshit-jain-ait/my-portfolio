# Harshit Jain - Portfolio

Clean, modern developer portfolio website ready for instant deployment on [Vercel](https://vercel.com).

## 🚀 Quick Deployment to Vercel

### Option 1: Deploy with Vercel CLI (Recommended)

1. Open your terminal in this directory:
   ```bash
   cd "Project"
   ```
2. Run Vercel CLI to deploy:
   ```bash
   npx vercel
   ```
3. Follow the prompts:
   - Set up and deploy: **Y**
   - Which scope: *(Select your account)*
   - Link to existing project: **N**
   - Project name: `harshit-jain-portfolio` (or your preferred name)
   - In which directory is your code located: `./`
4. For production deployment:
   ```bash
   npx vercel --prod
   ```

---

### Option 2: Deploy via GitHub + Vercel Dashboard

1. Push this project to your GitHub repository.
2. Go to [vercel.com](https://vercel.com) and click **"Add New..."** -> **"Project"**.
3. Import your GitHub repository.
4. If this folder is inside a parent repository, set **Root Directory** to `Project`.
5. Click **"Deploy"**.

---

## 🛠 Local Development

To run locally:
```bash
npx serve .
```
Or open [index.html](./index.html) directly in any modern web browser.
